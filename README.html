ZyZoom Internet Downloader

A lightweight download manager for Windows 7 and newer, with a built-in aria2 engine and browser integration.

Overview

ZyZoom Internet Downloader downloads files over HTTP, HTTPS and FTP, splits transfers into parallel connections, resumes interrupted downloads and can fetch video and audio streams from YouTube through the browser extension.

The interface is available in 20 languages; change it under Options > Settings.

Requirements

  • Windows 7 SP1 or newer (32-bit or 64-bit).
  • .NET Framework 2.0 or newer.
  • Internet Explorer 8 or newer for the built-in interface; IE11 is recommended on Windows 7 and later.
  • About 20 MB of free disk space (the aria2 engine is included).

Installation

  1. Run setup.exe and approve the administrator prompt.
  2. Keep the default folder (%ProgramFiles%\ZyZoom Internet Downloader) or choose another one.
  3. Setup creates Start Menu and Desktop shortcuts and registers an uninstaller.

Upgrading keeps your settings in %APPDATA%\ZID and leaves downloaded files untouched.

Portable copy: unzip the portable folder and run ZID.exe; no installer is needed. A fresh copy in a writable folder keeps settings, the log and downloads in data\ next to the program. An existing %APPDATA%\ZID is reused, and a read-only program folder falls back to it.

First run

  1. Click Add URL, paste a URL, choose a save folder and click OK; the download starts immediately.
  2. Use the toolbar or the right-click menu to pause, resume, restart or remove items.
  3. Downloads can also be queued or scheduled from the same window.

You can also drag and drop links onto the window. Clipboard watching is optional and off by default (Options > Settings).

Browser integration

Open Options > Browser integration and choose your browser family.

  • Chromium (Edge, Brave, Opera, Vivaldi, ...): close the browser completely, then let the app open it with the local extension. On Google Chrome 137 and later, open chrome://extensions, enable Developer mode, choose Load unpacked and select the zid-crx folder inside the program folder.
  • Firefox: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on and select zid-xpi\manifest.json. Firefox removes temporary add-ons when it restarts.

On YouTube, open a video, click the floating ZID button, pick a quality and press Download. Video and audio are downloaded as separate files; merging is not included.

Uninstall

Open Control Panel > Programs and Features and remove ZyZoom Internet Downloader. Your settings and downloaded files are kept.

Troubleshooting

  • "aria2c.exe not found": the tools folder is missing; reinstall.
  • YouTube download fails: reload the browser extension and add the video again; old links expire.
  • Browser integration does not connect: make sure only one copy of the app is running and port 10007 is free. Logs are in data\app.log (portable) or %APPDATA%\ZID\app.log.
  • Windows 7: enable .NET Framework 3.5 (it includes 2.0) in Windows Features if the app does not start.

Credits

Downloads use aria2 (GPLv2); TLS uses OpenSSL. License files are in tools\COPYING and tools\LICENSE.OpenSSL.

ZyZoom Internet Downloader

Un gestionnaire de téléchargements léger pour Windows 7 et versions ultérieures, avec le moteur aria2 intégré et l'intégration au navigateur.

Présentation

ZyZoom Internet Downloader télécharge des fichiers via HTTP, HTTPS et FTP, divise les transferts en connexions parallèles, reprend les téléchargements interrompus et récupère les flux vidéo et audio de YouTube grâce à l'extension de navigateur.

L'interface est disponible en 20 langues ; modifiez-la dans Options > Paramètres.

Configuration requise

  • Windows 7 SP1 ou version ultérieure (32 ou 64 bits).
  • .NET Framework 2.0 ou version ultérieure.
  • Internet Explorer 8 ou version ultérieure pour l'interface intégrée ; IE11 est recommandé sous Windows 7 et ultérieur.
  • Environ 20 Mo d'espace disque libre (le moteur aria2 est inclus).

Installation

  1. Lancez setup.exe et acceptez l'invite d'administrateur.
  2. Conservez le dossier par défaut (%ProgramFiles%\ZyZoom Internet Downloader) ou choisissez-en un autre.
  3. L'installation crée les raccourcis du menu Démarrer et du Bureau et enregistre un désinstalleur.

Une mise à jour conserve vos paramètres dans %APPDATA%\ZID et ne touche pas aux fichiers téléchargés.

Premier démarrage

  1. Cliquez sur Ajouter une URL, collez une URL, choisissez un dossier de destination et cliquez sur OK ; le téléchargement démarre immédiatement.
  2. Utilisez la barre d'outils ou le menu contextuel pour mettre en pause, reprendre, redémarrer ou supprimer des éléments.
  3. Les téléchargements peuvent aussi être mis en file d'attente ou planifiés depuis la même fenêtre.

Vous pouvez aussi glisser-déposer des liens sur la fenêtre. La surveillance du presse-papiers est facultative et désactivée par défaut (Options > Paramètres).

Intégration au navigateur

Ouvrez Options > Intégration au navigateur et choisissez votre famille de navigateur.

  • Chromium (Edge, Brave, Opera, Vivaldi, ...) : fermez complètement le navigateur, puis laissez l'application l'ouvrir avec l'extension locale. Avec Google Chrome 137 et ultérieur, ouvrez chrome://extensions, activez le mode développeur, cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier zid-crx dans le dossier du programme.
  • Firefox : ouvrez about:debugging#/runtime/this-firefox, cliquez sur Charger un module complémentaire temporaire et sélectionnez zid-xpi\manifest.json. Firefox supprime les modules temporaires au redémarrage.

Sur YouTube, ouvrez une vidéo, cliquez sur le bouton flottant ZID, choisissez une qualité et cliquez sur Télécharger. La vidéo et l'audio sont téléchargés séparément ; la fusion n'est pas incluse.

Désinstallation

Ouvrez Panneau de configuration > Programmes et fonctionnalités, puis supprimez ZyZoom Internet Downloader. Vos paramètres et fichiers téléchargés sont conservés.

Dépannage

  • « aria2c.exe introuvable » : le dossier tools manque ; réinstallez.
  • Le téléchargement YouTube échoue : rechargez l'extension et ajoutez la vidéo à nouveau ; les anciens liens expirent.
  • L'intégration au navigateur ne se connecte pas : vérifiez qu'une seule copie de l'application est ouverte et que le port 10007 est libre. Les journaux se trouvent dans %APPDATA%\ZID\app.log.
  • Windows 7 : activez .NET Framework 3.5 (qui inclut 2.0) dans Fonctionnalités Windows si l'application ne démarre pas.

Crédits

Les téléchargements utilisent aria2 (GPLv2) ; TLS utilise OpenSSL. Les licences se trouvent dans tools\COPYING et tools\LICENSE.OpenSSL.

ZyZoom Internet Downloader

مدير تنزيلات خفيف لنظام Windows 7 والإصدارات الأحدث، مع محرك aria2 المدمج وتكامل مع المتصفح.

نظرة عامة

يقوم ZyZoom Internet Downloader بتنزيل الملفات عبر HTTP وHTTPS وFTP، ويقسّم التنزيلات إلى اتصالات متوازية، ويستأنف النقل المتوقف، ويجلب مقاطع الفيديو والصوت من YouTube عبر إضافة المتصفح.

الواجهة متوفرة بـ 20 لغة؛ غيّرها من الخيارات > الإعدادات.

المتطلبات

  • Windows 7 SP1 أو أحدث (32 بت أو 64 بت).
  • .NET Framework 2.0 أو أحدث.
  • Internet Explorer 8 أو أحدث للواجهة المدمجة؛ يُفضّل IE11 على Windows 7 وما بعده.
  • حوالي 20 ميغابايت من المساحة الحرة (محرك aria2 مضمّن).

التثبيت

  1. شغّل setup.exe ووافق على مطالبة المسؤول.
  2. اترك المجلد الافتراضي (%ProgramFiles%\ZyZoom Internet Downloader) أو اختر مجلداً آخر.
  3. ينشئ التثبيت اختصارات في قائمة ابدأ وعلى سطح المكتب ويسجّل أداة إزالة.

عند الترقية تُحفظ إعداداتك في %APPDATA%\ZID ولا تُمس الملفات التي تم تنزيلها.

البدء

  1. انقر إضافة URL، والصق عنوان URL واختر مجلد الحفظ، ثم انقر موافق؛ يبدأ التنزيل فوراً.
  2. استخدم شريط الأدوات أو قائمة النقر بزر الماوس الأيمن للإيقاف المؤقت أو الاستئناف أو إعادة البدء أو الإزالة.
  3. يمكن أيضاً وضع التنزيلات في قائمة الانتظار أو جدولتها من النافذة نفسها.

يمكنك أيضاً سحب الروابط وإفلاتها على النافذة. مراقبة الحافظة اختيارية ومعطّلة افتراضياً (الخيارات > الإعدادات).

تكامل المتصفح

افتح الخيارات > تكامل المتصفح واختر عائلة المتصفح.

  • متصفحات Chromium (Edge وBrave وOpera وVivaldi...): أغلق المتصفح تماماً، ثم دع التطبيق يفتحه مع الإضافة المحلية. في Google Chrome 137 وما بعده، افتح chrome://extensions، وفعّل وضع المطوّر، واختر Load unpacked، ثم حدّد مجلد zid-crx داخل مجلد البرنامج.
  • Firefox: افتح about:debugging#/runtime/this-firefox، وانقر Load Temporary Add-on، وحدّد zid-xpi\manifest.json. يزيل Firefox الإضافات المؤقتة عند إعادة التشغيل.

على YouTube، افتح فيديو، وانقر زر ZyZoom العائم، واختر الجودة، ثم انقر Download. يتم تنزيل الفيديو والصوت كملفين منفصلين؛ الدمج غير مضمّن.

إلغاء التثبيت

افتح لوحة التحكم > البرامج والميزات، ثم أزل ZyZoom Internet Downloader. تُحفظ إعداداتك وملفاتك التي تم تنزيلها.

استكشاف الأخطاء

  • «aria2c.exe غير موجود»: مجلد tools مفقود؛ أعد التثبيت.
  • فشل تنزيل YouTube: أعد تحميل إضافة المتصفح وأضف الفيديو مرة أخرى؛ الروابط القديمة تنتهي صلاحيتها.
  • لا يتصل تكامل المتصفح: تأكد من تشغيل نسخة واحدة فقط من التطبيق وأن المنفذ 10007 غير مستخدم. السجلات في %APPDATA%\ZID\app.log.
  • Windows 7: فعّل .NET Framework 3.5 (يتضمن 2.0) من ميزات Windows إذا لم يبدأ التطبيق.

الشكر والتقدير

يستخدم التنزيل aria2 (GPLv2) وTLS يستخدم OpenSSL. ملفات الترخيص في tools\COPYING وtools\LICENSE.OpenSSL.
